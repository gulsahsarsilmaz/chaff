# Code of Conduct

## Our standard

This project adopts the [Contributor Covenant, version 2.1][cc] as its code of conduct.
The full text is available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: participate with respect. Assume good faith, disagree about the work rather than
the person, and accept that maintainers make the final call on scope. Harassment,
personal attacks, and demeaning or exclusionary behaviour are not tolerated, in issues,
pull requests, commit messages or anywhere else this project is discussed.

## Scope

This applies in all project spaces, and when an individual is representing the project in
public.

## Enforcement

Report unacceptable behaviour privately to the maintainers via
[GitHub's private reporting][report]. Reports are reviewed and responded to within
72 hours, and the reporter's identity is not disclosed to the person reported.

Maintainers may warn, temporarily block, or permanently ban any contributor for behaviour
they judge to breach this code. Enforcement decisions are not debated in public threads.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
[report]: https://github.com/lockdownmedia/chaff/security/advisories
